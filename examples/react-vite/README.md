# Liquid Glass: React + Vite example

A standalone app that installs [`react-webgl-liquid-glass`](https://www.npmjs.com/package/react-webgl-liquid-glass) from npm: a scrolling page with a sticky glass navbar, glass cards in normal layout, a fixed glass button and a playground with sliders.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/aliajafari/Liquid-Glass-with-WebGL/tree/main/examples/react-vite?file=src%2FApp.tsx)

```bash
npm install
npm run dev
```
